
# astroMoonBot — лунный ассистент

## 📖 О проекте
Telegram-бот с функциями лунного календаря, астрологических советов и встроенной CRM-системой для приема и обработки заявок на консультации. 
Проект реализован по полному циклу: от написания Технического Задания (ТЗ) до разработки асинхронного бота и админ-панели.

## ⚙️ Основной функционал
*   **Для клиентов:** получение данных о лунном дне, знаке зодиака, случайные советы, оформление заявки на консультацию.
*   **Для администратора (астролога):** получение уведомлений о заявках, ответы клиентам в один клик, фильтрация заявок по статусам (новые, оплаченные, отвеченные) через служебные команды.

## Установка

1. Установите Python 3.8+.
2. Клонируйте проект и перейдите в папку.
3. Создайте виртуальное окружение и активируйте его.
4. Установите зависимости:
